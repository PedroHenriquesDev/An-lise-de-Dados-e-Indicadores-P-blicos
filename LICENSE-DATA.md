# Licença dos dados processados e do texto

Os **dados processados** (`data/processed/`), o **dicionário de dados** e o **texto do artigo**
(`docs/`) produzidos por este projeto são licenciados sob
[Creative Commons Atribuição 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.pt-br).

## Dados originais (PRF)

Os dados brutos pertencem à Polícia Rodoviária Federal (PRF) e são publicados como dados abertos em:
https://www.gov.br/prf/pt-br/acesso-a-informacao/dados-abertos/dados-abertos-da-prf

O conteúdo do site da PRF informa estar sob licença CC BY-ND 3.0 (Atribuição-SemDerivações).
Este projeto **não relicencia** os dados originais: a licença CC BY 4.0 acima se aplica apenas
ao material novo produzido pela equipe. Sempre cite a PRF como fonte.

> Dúvida de enquadramento (dados derivados vs. "SemDerivações")? Confirme com o docente.
